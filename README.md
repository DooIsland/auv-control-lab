# AUV 控制实验室

用于调试水下机器人控制算法的本地 Web 仿真平台，支持三维航点导航和多算法对比。

## 下载与运行

[下载最新 Windows x64 便携包](https://github.com/DooIsland/auv-control-lab/releases/latest/download/AUV-Control-Lab-Windows-x64.zip)

1. 下载 ZIP 并解压。
2. 双击 `AUV-Control-Lab.exe`，程序会打开默认浏览器。
3. 保持启动窗口打开，或使用网页里的“退出程序”停止服务。

无需另外安装 Python、Node.js 或开发工具。首次启动需要数秒解压内置运行环境。若浏览器未自动打开，请复制启动窗口显示的地址。8000 端口占用时程序自动改用空闲端口。

## 功能

- 全屏三维水下场景与二维俯视地图，航点位置和深度可编辑。
- 二维/三维 LOS 导引，支持单点和多航点任务。
- 航向、速度、深度三通道 PID 与可调 Q/R 的 LQR。
- 网页 Python 控制器编辑器，受限语法在独立子进程中执行。
- 算法对比、控制响应、执行器输出、限幅提示与误差指标。
- 线性/二次阻力、海流、浮力偏差、执行器延迟和传感器噪声。
- 实验配置与代码保存/加载、浏览器本地恢复、CSV 导出。
- 浮动窗口拖动、缩放和折叠，以及日志查看和程序退出。

## 版本与验证范围

当前版本：**v1.2.1**。

已通过 69 项后端测试、4 项前端逻辑测试、15,000 步仿真、连续 30 次 HTTP 仿真请求及 3 轮独立 exe 启停验证。尚未在另一台 Windows 电脑验收，浏览器视觉/拖拽和长时间 GPU/内存验收也尚未完成。

这是简化算法调试平台，没有完整六自由度水动力、海床碰撞或 CFD，不用于真实机器人控制和科研可信度验证。程序仅监听本机。自定义控制器不支持任意 Python 包导入。
